출장 여비 산출기

2026학년도 학교회계 예산편성 기본지침(전라남도교육청) 여비 집행 기준 기반

1. 출장 정보

출발·복귀 일시를 입력하면 일수, 숙박 박수, 근무지 내 출장 시간이 자동으로 채워집니다.

2. 거리·운임

카카오 REST API 키를 설정에 입력하면 주소로 거리를 조회합니다. 키가 없으면 거리·운임을 직접 입력하세요.
운임을 입력하지 않고 거리×추정단가로 계산 (참고용 추정치)
왕복 운임 계산

3. 감액·조정 (지침 기준)

식사가 제공됨 (해당 일수 식비 제외 — 이중 지급 금지)
숙박이 제공됨 (숙박비 제외)
친지 집에서 숙박 (1박 20,000원 정액)
인솔 출장으로 현지교통비가 소요되지 않음 (일비 1/2 감액)
야영지 숙박 (숙박비 미지급)

산출 결과

운임·숙박비는 실비정산, 일비·식비는 정액입니다. 최종 지급액은 증빙서류와 최신 「공무원 여비 규정」에 따라 확정하세요.

출장지 근처 주유소 (증빙용)

출장지를 입력하고 검색하세요. API 키가 없으면 '카카오맵에서 보기'로 검색 결과를 열 수 있습니다.
자가용 출장의 운임은 지침상 대중교통 요금으로 지급되므로, 주유 영수증이 여비 증빙에 해당하는지는 학교 행정실에 확인하세요.
설정: 단가 및 API 키

기본값은 지침과 공무원 여비 규정 기준(일비·식비 25,000원, 숙박비 상한 70,000/80,000/100,000원, 친지 숙박 20,000원)입니다. 근무지 내 출장 단가(20,000/10,000원)와 철도·버스 추정단가는 지침 PDF에 없어 확인이 필요합니다. 개정 시 여기서 수정하세요.
